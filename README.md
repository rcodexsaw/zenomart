# ⚡ ZenoMart — Modern E-Commerce Application

> A sleek, high-performance e-commerce frontend web application built with React, Vite, and Tailwind CSS.

---

## 🌟 Features

- 🔐 **Authentication Flow**: Complete Login & Register system with protected and public routing logic.
- 🛍️ **Interactive Shopping Experience**: Dynamic product rendering, filtering, and detailed product view pages.
- 🛒 **Real-time Cart System**: Side drawer cart management with quick add/remove and item quantity updates.
- 🎨 **Modern Dark UI**: Beautiful futuristic dark-themed UI built with custom Tailwind styles and blur effects.
- 📱 **Fully Responsive Layout**: Smooth user experience across desktop, tablet, and mobile devices.

---

## 🛠️ Tech Stack

- **Frontend**: React.js, Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Routing**: React Router (`react-router-dom` / `react-router`)
- **State Management**: React Context API
